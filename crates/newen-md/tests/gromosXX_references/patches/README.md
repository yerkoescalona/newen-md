Applied with `git apply` to gromosXX md++ 247c95c4 (D1, D2, D16, D25, D32, D40, D41, LS1, LS2,
LS3) and gromos++ 9cd9f6b3
(D4, D5, D8), rebuilt as in `BUILD.md`. A reference
system whose `input.toml` names one of these patches was generated by the patched binary; its
expected output is the *intended* behaviour, not the released one. The unpatched binary remains the
oracle for every other reference.

The three A-EDS patches apply each on its own to 247c95c4 and together with D1 and D2; the patched
binary built with all five regenerates the D1/D2 references byte for byte. D16 and D25 are the
dossier's row numbers (`math/lean/docs/gromos-divergences.md`, D16 bullet 1; D25); D32 is new.

LS1–LS3 are the lattice-sum defects of the lattice-sum port; their dossier IDs are pending. Each
applies alone to 247c95c4. The finite-difference field of P3M in a skewed cell (gromosXX takes the
derivative along each lattice axis as the Cartesian component, `latticesum.cc:626-641`) has no
patch yet, so the triclinic P3M reference uses ik differentiation (NFDORD 0).
