# Patches to native gromosXX used as a corrected oracle

Applied with `git apply` to gromosXX md++ 247c95c4 (D1, D2, D16, D25, D32, D40, D41) and gromos++ 9cd9f6b3
(D4, D5, D8), rebuilt as in `BUILD.md`. A reference
system whose `input.toml` names one of these patches was generated by the patched binary; its
expected output is the *intended* behaviour, not the released one. The unpatched binary remains the
oracle for every other reference.
